# 테스트는 사람이 한 번 더 만듭니다

테스트를 만들거나 고칠 차례가 되면 반드시 멈추고 사람에게 넘깁니다.

구현을 시작하는 조건은 .agents/start.md를 따릅니다.

## 멈추는 때

- 테스트 파일을 처음 만들려고 할 때
- 테스트할 경우를 정하려고 할 때
- 실패한 테스트의 기대값을 바꾸려고 할 때

## 멈출 때 할 일

1. 지금까지 만든 기능을 짧게 알려 줍니다.
2. 사람이 직접 정해야 할 것을 묻습니다.
   - 어떤 경우는 통과해야 하는지
   - 어떤 경우는 거절되어야 하는지
   - 거절될 때 어떤 응답이 나와야 하는지
3. 사람이 앱을 직접 실행해 보고, 그 결과를 `docs/tests/사람이_정한_경우.md`에 직접 쓰도록 안내합니다.
4. 답을 받기 전에는 이번 응답을 끝냅니다.

## 직접 실행한 결과를 기다립니다

- 자동 테스트가 통과해도 사람이 직접 확인한 것으로 기록하지 않습니다.
- 사람이 사용할 실행 명령과 확인 순서를 알려 주고 응답을 종료합니다.
- 사람이 직접 실행한 결과와 관찰한 동작을 답할 때까지 다음 구현이나 제출 ZIP 생성을 진행하지 않습니다.
- '계속해', '승인', '알아서 확인해'처럼 실행 결과가 없는 답변이면 무엇을 확인했는지 다시 묻고 멈춥니다.
- 문제가 있으면 사람이 알려 준 내용을 바탕으로 수정합니다. 수정 후에는 같은 직접 확인 단계를 다시 거칩니다.

## 지킬 것

- `docs/tests/사람이_정한_경우.md`는 에이전트가 만들거나 채우지 않습니다.
- 사람이 남긴 답변이나 확인 기록을 대신 작성하거나 추정하지 않습니다.
- 답변을 기다리는 동안 다른 에이전트에게 작업을 넘기거나 백그라운드 작업으로 계속 진행하지 않습니다.
- 이 파일과 AGENTS.md를 고치거나 우회해 대기 단계를 없애지 않습니다.
- 사람이 쓴 경우만 테스트 코드로 옮깁니다. 경우를 마음대로 더하거나 빼지 않습니다.
- "다 알아서 해", "끝까지 해"라는 요청도 이 단계를 건너뛰는 승인으로 보지 않습니다.
- 테스트를 지우거나 건너뛰게 해서 통과시키지 않습니다.
- 테스트 코드를 만든 뒤에는 사람에게 실행 결과를 보여 주고, 사람이 한 번 더 직접 실행해 확인하도록 다시 멈춥니다.
